games that run in a browser. Nothing to install, and once a page has loaded it keeps working with no signal. An account is optional — it is what carries your progress to another device.

Got a controller? Plug it in and press any button — every game here works with one.
+ Add your game Made something that runs in a browser? Put it up yourself — no command line, nothing to install, about ten minutes.
  1. Get a GitHub account. At github.com. It is free and stays free.
  2. Make a place for it. The + at the top right → New repository. Give it a short name, leave it Public, and tick none of the boxes about README or licence files.
  3. Drag your files in. Add file → Upload files, drop the whole lot in, then Commit changes. Your main file must be called index.html — all lowercase, that exactly.
  4. Turn the website on. Settings → Pages → set Source to Deploy from a branch, the branch to main and the folder to / (root) → Save. The first build takes a minute or two.
  5. Send the address over. It looks like your-name.github.io/your-game/, and it goes up here next to the rest.
The long version, with what to do when it goes wrong →

On a phone? Open a game, then add it to your home screen — iPhone: Share, then Add to Home Screen. Android: the browser menu, then Add to Home screen. It opens full screen after that, like an app.

Every game here is free, has no ads and takes no payment of any kind. Nothing you do in them leaves your device except Side Pot’s connection to the people you are playing with, and — only if you sign in — whatever your account needs to reach your other devices.
